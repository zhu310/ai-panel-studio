# AI Panel Studio

面向知识工作者的 AI 圆桌讨论 Web App。用户给出议题并确认由 AI 生成的主持人与专家阵容后，在演播厅观看一场有角色差异、实时状态和可追溯共识/分歧的讨论。

## 当前状态

项目处于**阶段 0：需求工程、架构设计与开发规划**。当前仓库只含规划文档与 Git 忽略规则；未安装依赖、未创建前后端代码、未调用模型 API，也没有可运行服务。
